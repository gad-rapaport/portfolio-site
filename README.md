# Gadi Rapaport — Build Studio

Portfolio site: four case studies on a stage (DevMarshal, Slotkeeper, Planwright, Signalpost), two more builds
(Fieldline, Airwise), how I work with AI agents, and contact. Plan: `portfolio-plan.md` on the desktop.

```powershell
npm install
npm run dev        # http://127.0.0.1:8110
npm run build      # type-check + static build in dist/
```

## Content

- `src/data/projects.ts` — the single source of truth for every project. Every number there comes from the
  project's own repository; keep it that way.
- `src/data/media.json` and `public/media/` — generated by `npm run media` (`scripts/sync-media.mjs`) from
  `C:\dev\portfolio\<project>`: posters, looping previews, films and WebP screenshots. Needs ffmpeg.
- `src/data/mission-log.json` — generated by `scripts/build-mission-log.mjs` from DevMarshal's real Milestone B
  event log (57 of 213 events; bookkeeping events dropped).
- Languages: English and Hebrew (RTL). Interface text lives in `src/i18n/strings.ts` (the Hebrew object must
  match the English shape), project text in `src/i18n/projects.he.ts` (arrays line up with `projects.ts`).
  `?lang=he` opens Hebrew; the choice is remembered per browser.
- CVs: `public/gadi-rapaport-cv.pdf` (English) and `public/gadi-rapaport-cv-he.pdf` (Hebrew). If the English
  file is missing, the site offers "Request CV" by email instead of a broken download.
- Diploma: `public/media/certificate.webp` (+ `-thumb`) is rendered from the original PDF with the ID number
  painted out on the pixels. Never publish the original PDF.

## The page

- URL state: `?p=<project>&l=product|hood|build` opens a project on a layer; `?view=overview` is the one-page
  quick overview (also the calm path for reduced motion).
- Ctrl/⌘+K command palette; arrow keys move between projects; Escape closes dialogs and returns focus.
- Intro plays once per session, is skippable, and never runs with reduced motion.
- Demos are labelled for what they are: DevMarshal's replay is the real event log; Slotkeeper's is a replay of
  the measured result (no server call); Planwright's is an illustration with made-up amounts; Signalpost shows
  two real screenshots.
