אותו פרומפט בשני פורמטים. אין צורך לצרף את שניהם. הקבצים המקוריים נשמרו ללא שינוי.

איך מתחילים?

  1. פותחים תיקיית פרויקט ב־Codex. מצרפים את הפרומפט ומתארים מה רוצים לבנות, עבור מי ומה צריך להיכלל בגרסה הראשונה.
  2. מכינים מסמכים שמתאימים לרעיון. מבקשים הגדרת מוצר, תוכנית עבודה, ארכיטקטורה, כללי עבודה ובדיקות. משלימים שאלות מהותיות לפני שממשיכים.
  3. עוברים על התוכנית. בודקים שהדרישות נכונות, שהמשימות קטנות וברורות ושיש דרך לבדוק הצלחה. המסמכים הם בסיס עבודה, לא הוכחה שמוצר מוכן.
  4. ממשיכים ב־Claude Code באותה תיקייה. מבקשים לקרוא את ההנחיות ואת המסמכים הרלוונטיים, לבחור את המשימה הראשונה שלא הושלמה, לבצע אותה ולבדוק את התוצאה.

התאם את הפרומפט לרעיון. שאל שאלות מהותיות, הפרד הנחות מדרישות וצור את מסמכי הבסיס ותוכנית העבודה. בשלב הזה אל תתחיל לממש פיצ׳רים. שמור בתיקייה את המידע שיאפשר לכלי אחר להמשיך בלי היסטוריית השיחה.

טקסט מעבר ל־Claude Code

אנחנו ממשיכים פרויקט קיים באותה תיקייה.
קרא את הנחיות הפרויקט ואת מסמכי המוצר, התוכנית, הארכיטקטורה והבדיקות הרלוונטיים. בדוק את מצב Git.
סכם בקצרה את המצב, בחר את המשימה הראשונה שאפשר לבצע מתוך התוכנית, וממש אותה בצעד קטן. הרץ את הבדיקות המתאימות ועדכן את התוכנית לפי התוצאות בפועל. אל תתחיל מחדש ואל תסמן משימה כבוצעה בלי אימות.

זו שיטת עבודה מוצעת, לא דרישה של Codex או Claude Code. אפשר להשתמש בכל אחד מהם גם לתכנון וגם לפיתוח. התאימו את כמות התיעוד להיקף הפרויקט.
